# Login Signup Page

A simple login and signup page built with React and CSS.

## Technologies Used
- React
- Vite
- JavaScript
- CSS

## Features
- User registration form
- Login form with validation
- Persistent local storage support
- Responsive layout
- Home dashboard after successful login

## Run the app locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
